# 💻 CH01 — Commands

> **Chapter:** Project Planning & Vision

---

# 📖 Overview

Unlike the remaining chapters of the CartWise handbook, **Chapter 1 focuses entirely on project planning, vision, and engineering decisions.**

Since no actual software development or environment setup takes place during this stage, **there are no project-specific commands to execute.**

Instead, this chapter establishes:

- The project vision
- The problem statement
- Engineering goals
- Project scope
- Documentation philosophy
- Development roadmap

Implementation begins in **Chapter 2 – Project Initialization**.

---

# 🚫 Commands Used

There are **no terminal commands** required for this chapter.

| Command | Purpose |
|---------|---------|
| None | This chapter is purely conceptual and contains no implementation. |

---

# 🤔 Why Are There No Commands?

Software engineering does not begin with writing code.

Before developers create files, install frameworks, or initialize repositories, they must answer questions such as:

- What problem are we solving?
- Who are the users?
- Why should this product exist?
- What features belong in the first release?
- Which technologies should we choose?
- How will the project scale?

These decisions are made during the planning phase and therefore do not require any terminal commands.

# 📌 What Happens in the Next Chapter?

Beginning with **Chapter 2 – Project Initialization**, we start building the CartWise project.

Commands introduced there include:

## Node.js

```bash
node -v
```

Checks the installed Node.js version.

---

## npm

```bash
npm -v
```

Checks the installed npm version.

---

## Create Vite Project

```bash
npm create vite@latest
```

Creates a new Vite application.

---

## Install Dependencies

```bash
npm install
```

Downloads and installs all project dependencies.

---

## Start Development Server

```bash
npm run dev
```

Starts the local development server.

---

## Git Initialization

```bash
git init
```

Initializes a new Git repository.

---

## First Commit

```bash
git add .
git commit -m "Initial CartWise setup"
```

Creates the initial project commit.
