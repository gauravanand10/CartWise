# 📖 CH01 — Glossary

> A quick reference for the important terms introduced in **Chapter 1 – Project Planning & Vision**.

---

# A

## Agile

A software development methodology where projects are built in small, incremental iterations instead of one large release.

### CartWise Context

CartWise is developed chapter by chapter. Every implemented feature is documented before moving to the next one.

---

## AI (Artificial Intelligence)

Artificial Intelligence refers to computer systems capable of performing tasks that normally require human intelligence, such as reasoning, prediction, recommendation, and natural language understanding.

### CartWise Context

AI is not yet implemented. It will later power:

- Product Recommendations
- AI Shopping Assistant
- Price Prediction
- Review Summarization
- Smart Product Comparison

---

## Architecture

Architecture is the high-level design of a software system.

It defines:

- Structure
- Components
- Communication
- Data Flow
- Responsibilities

Good architecture makes software easier to maintain and scale.

---

# B

## Business Problem

The real-world challenge that a software product aims to solve.

### CartWise Context

Users spend too much time comparing products across multiple shopping websites before making purchasing decisions.

---

# C

## CartWise

CartWise is an AI-powered Product Comparison Platform built to help users compare products, prices, specifications, and reviews from multiple stores in one place.

It also serves as a production-grade Software Engineering learning project.

---

## Customer

The end user who uses a software product.

### CartWise Context

Anyone shopping online who wants to make better purchasing decisions.

---

# D

## Documentation

Written information that explains how software is planned, developed, maintained, and used.

Examples include:

- README
- API Documentation
- Architecture Documents
- User Manuals
- Developer Guides

---

## Documentation-Driven Development

An engineering practice where documentation evolves alongside implementation instead of being written after the project is finished.

CartWise follows this philosophy.

---

# E

## Engineering

The process of designing, building, testing, improving, and maintaining systems using proven principles and best practices.

Software Engineering applies these principles to software development.

---

# F

## Feature

A specific capability provided by software.

Examples:

- Search
- Wishlist
- Product Comparison
- Authentication

Every feature solves a user problem.

---

# G

## Goal

The primary objective that a project aims to achieve.

### CartWise Goal

Help users compare products faster and make smarter purchasing decisions.

---

# I

## Incremental Development

A development approach where software is built one feature at a time.

Instead of building everything together, the project grows continuously.

---

## Iteration

One complete cycle of:

- Planning
- Development
- Testing
- Improvement

Software typically evolves through many iterations.

---

# M

## Maintainability

The ease with which software can be modified, extended, debugged, or improved.

Maintainable software usually has:

- Clean Architecture
- Good Documentation
- Modular Code
- Reusable Components

---

## Milestone

A major achievement during project development.

Examples:

- Homepage Completed
- Routing Implemented
- Backend Integrated
- Authentication Added

---

# P

## Planning

The process of deciding what will be built, why it should be built, and how it should be built before development begins.

Planning reduces uncertainty and minimizes future rework.

---

## Product

Software created to solve a real-world problem.

CartWise is a software product.

---

## Product Vision

A long-term description of what a product aims to become.

It acts as the guiding direction for future development.

### CartWise Vision

To become an intelligent shopping companion that helps users make informed purchasing decisions.

---

## Project

A temporary effort undertaken to build a unique product or service.

CartWise is a Software Engineering project.

---

## Project Scope

The boundary of what is included and excluded from the current project.

### Current Scope

- Frontend
- Homepage
- Routing
- Design System
- Shared Components

### Future Scope

- Backend
- Authentication
- Database
- AI
- Mobile Application

---

# R

## Requirement

A condition or capability that software must satisfy.

Requirements are generally divided into:

### Functional Requirements

Describe what the software should do.

Example:

Search Products

### Non-Functional Requirements

Describe how the software should behave.

Examples:

- Performance
- Security
- Reliability
- Scalability

---

## Roadmap

A high-level timeline showing how a project will evolve.

The CartWise roadmap spans from project planning to production deployment.

---

# S

## Scalability

The ability of software to continue performing efficiently as the number of users, requests, or data increases.

Good architecture supports scalability.

---

## Scope Creep

The uncontrolled addition of new features without proper planning.

Scope creep often leads to delays and increased project complexity.

---

## Software Engineering

The systematic approach to designing, developing, testing, deploying, and maintaining software systems.

It combines engineering principles with programming.

---

## Stakeholder

Any person or organization affected by a software project.

Examples include:

- Developers
- Users
- Businesses
- Product Owners

---

# T

## Technical Debt

The future cost created by taking shortcuts during software development.

Examples:

- Poor Documentation
- Duplicate Code
- Temporary Fixes
- Weak Architecture

Technical debt should be minimized whenever possible.

---

## Technology Stack

The collection of tools and technologies used to build a software application.

### Current CartWise Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React

### Planned Stack

- Spring Boot
- PostgreSQL
- Docker
- GitHub Actions
- OpenAI API
- Gemini API

---

# U

## User

A person who interacts with a software application.

For CartWise, the user is an online shopper looking for the best product.

---

# V

## Vision Statement

A concise statement describing the future direction of a software product.

It answers the question:

> *"What do we want this product to become?"*

The CartWise vision is to simplify online shopping through intelligent product comparison and AI-powered insights.

---

# 📌 Summary

This glossary introduced the core planning and software engineering terminology used throughout Chapter 1. Understanding these terms will make the upcoming chapters easier to follow as CartWise evolves from an idea into a production-ready software product.
