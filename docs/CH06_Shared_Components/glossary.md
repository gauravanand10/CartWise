# 📖 CH06 — Glossary

> This glossary explains the reusable UI components and design concepts introduced in the **Shared Components** chapter of CartWise.

---

# 🧩 Shared Component

A Shared Component is a reusable UI element that can be used across multiple pages and features.

Instead of creating the same UI repeatedly, developers build it once and reuse it throughout the application.

### CartWise Context

Examples include:

- Button
- Card
- Badge
- Chip
- Input
- Loader
- Skeleton
- PriceTag
- Rating
- StoreBadge
- ErrorState
- EmptyState
- SectionHeading

---

# 🔘 Button

A reusable interactive component used to trigger an action.

Examples:

- Search
- Compare
- Add to Wishlist
- View Details

Buttons maintain a consistent appearance and behavior throughout CartWise.

---

# 🪪 Card

A Card is a container used to group related information.

Examples:

- Product Cards
- Brand Cards
- Offer Cards

Cards improve content organization and readability.

---

# 🏷️ Badge

A Badge is a small visual label used to highlight important information.

Examples:

- New
- Best Seller
- Trending
- Sale

Badges quickly draw the user's attention.

---

# 🎟️ Chip

A Chip is a compact UI element representing a category, filter, or selection.

Examples:

- Electronics
- Mobiles
- Laptops
- Fashion

Chips provide quick filtering and navigation.

---

# ⌨️ Input

An Input component allows users to enter information.

Examples:

- Search Bar
- Login Form
- Registration Form

Inputs provide a consistent experience across forms.

---

# ⏳ Loader

A Loader informs users that data is currently being processed.

Examples:

- Product Loading
- Search Results Loading
- API Requests

Loaders improve perceived responsiveness.

---

# 🦴 Skeleton

A Skeleton is a placeholder that mimics the layout of content while real data is loading.

Instead of showing a spinner alone, Skeletons reduce perceived waiting time by displaying the approximate structure of the final content.

---

# ❌ ErrorState

An ErrorState is displayed when something goes wrong.

Examples:

- Network Failure
- Server Error
- Failed Search

It provides feedback and often suggests corrective actions.

---

# 📭 EmptyState

An EmptyState appears when there is no data available.

Examples:

- Empty Wishlist
- No Search Results
- No Recently Viewed Products

Good EmptyStates guide users toward their next action.

---

# 💰 PriceTag

A reusable component responsible for displaying product prices.

It can include:

- Current Price
- Original Price
- Discount Percentage

Using a shared component ensures price formatting remains consistent.

---

# ⭐ Rating

A component used to display product ratings.

Examples:

- 4.8 ★
- 3.9 ★

Ratings help users evaluate product quality quickly.

---

# 🏪 StoreBadge

A visual label indicating the store from which a product originates.

Examples:

- Amazon
- Flipkart
- Croma
- Reliance Digital

Store badges improve product identification during comparisons.

---

# 📝 SectionHeading

A reusable heading component used to introduce sections throughout the application.

Examples:

- Flash Deals
- Trending Products
- AI Picks
- Recommended Products

Using one component keeps headings visually consistent.

---

# 🪟 GlassPanel

A reusable container implementing the Glassmorphism design style.

Characteristics include:

- Blur
- Transparency
- Soft Shadows
- Rounded Corners

Glass panels contribute to the premium visual identity of CartWise.

---

# ♻️ Reusability

Reusability is the practice of building components once and using them in multiple places.

Benefits include:

- Less duplicate code
- Easier maintenance
- Faster development
- Consistent UI

Shared Components are created specifically to maximize reusability.

---

# 🎨 UI Consistency

UI Consistency means similar elements should always look and behave the same.

For example:

- Every primary button should look identical.
- Every Product Card should follow the same layout.
- Every PriceTag should display prices in the same format.

Consistency improves usability and professionalism.

---

# 📦 Component Library

A Component Library is a collection of reusable UI components.

### CartWise Context

The Shared Components chapter establishes the foundation of CartWise's internal component library, which is reused across all pages and features.

---

# 📌 Summary

Shared Components are the building blocks of the CartWise interface. By creating reusable components such as Buttons, Cards, Inputs, Loaders, PriceTags, Ratings, and SectionHeadings, the project achieves greater consistency, reduces duplicate code, and becomes easier to maintain as new features are added.
